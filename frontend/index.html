      ABOUT THE CALCULATION

      A practical estimate, with the chemistry in view.

      The server calculates nonnegative fertilizer additions to bring the solution toward the selected ion targets. One fertilizer can supply several ions, so a close match for every ion may not be possible.

      All concentrations refer to the listed ionic species: nitrate, sulfate, and dihydrogen phosphate are not elemental nitrogen, sulfur, or phosphorus. This tool does not model nutrient removal, pH, precipitation, or changes in solution volume.
